# Rasoolicious — The Messenger of Deliciousness 🍫✨

A luxury artisanal dessert e-commerce website for **Rasoolicious**, handcrafted with React 19, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## 🌟 Features

- **Branded Experience**: Decadent bakery aesthetics with warm cocoa, caramel, and cream design language.
- **Interactive Brownie & Cake Showcases**: 3D card tilt effects, dynamic gallery, and real-time flavor highlights.
- **Rasoolicious Splash Loader**: Custom luxury loader with warm breathing glow, rising heart aroma steam, and baking status indicators.
- **Seamless Shopping & Cart**: Sliding Cart Drawer, coupon code validation (`RASOOL10`, `SWEETBOX`), and free shipping threshold meter.
- **Interactive Storytelling**: Scroll-driven video bakery showcase and craft highlights.
- **Wishlist & Customer Favorites**: Persistent client-side cart and wishlist state.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewing.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/hjebarson-byte/Rasoolious_Website.git
cd Rasoolious_Website

# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will be live at `http://localhost:5173`.

### Available Scripts

- `npm run dev`: Starts the Vite development server.
- `npm run build`: Type-checks and builds the production bundle in `dist/`.
- `npm run preview`: Locally previews the production build.
- `npm run lint`: Runs Oxlint for code quality.

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router DOM v7
